# Python Job Listings Web Scraper

## Project Overview

A Python web scraping project that collects job listing information and converts it into structured data for analysis.

## Data Collected

- Job title
- Company name
- Location
- Job detail page URL

## Technologies

- Python
- Requests
- Beautiful Soup
- Pandas
- Matplotlib
- Jupyter Notebook

## Project URL

https://roadmap.sh/projects/job-listings-scraper

## Repository

https://github.com/B0kkl/job-serching-engine

## Description

The scraper retrieves publicly available job listing data, extracts relevant fields, validates the collected records, exports the results to CSV, and performs basic exploratory data analysis.

## Disclaimer

This project is for educational and portfolio purposes. Always review and comply with a website's terms of service, robots.txt directives, and applicable laws before scraping or automating data collection.
